# Product

## Register

brand

## Users

Content creators, bloggers, and readers who want a modern, multi-language blog platform. They're looking for a clean, readable experience with dark/light mode support and professional design.

## Product Purpose

StandIdea is a multi-language blog platform built with Payload CMS and Next.js. It provides a beautiful, accessible reading experience with modern design principles, supporting Turkish and English content.

## Brand Personality

Clean, modern, and professional. StandIdea speaks with clarity and confidence. The tone is welcoming yet sophisticated - a platform that values quality content and excellent reading experience.

Three-word personality: **clean, modern, professional**.

## Anti-references

Avoid:
- **Cluttered layouts**: Keep reading experience focused and clean
- **Generic templates**: No cookie-cutter blog designs
- **Poor typography**: Font choices must support multi-language (TR/EN)
- **Dark mode pitfalls**: No pure black, use tinted darks
- **Over-decoration**: Every element must serve a purpose

## Design Principles

1. **Reading first**: Typography and spacing optimized for long-form content
2. **Multi-language ready**: Seamless Turkish/English experience
3. **Accessible**: WCAG 2.1 AA compliant
4. **Performant**: Fast loading, optimized for Cloudflare Workers
5. **Beautiful dark/light**: Thoughtful color system with amber accents

## Accessibility & Inclusion

- WCAG 2.1 AA compliance
- Keyboard navigation support
- Reduced motion support
- Semantic HTML
- Multi-language font support
